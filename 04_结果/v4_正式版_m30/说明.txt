v4 正式版 m30 说明
==================

一、版本
-------

正式名单：原始 19 支 ETF + XLC，共 20 支。
选择逻辑：时间互补贪心 + 边际 Average 下限 0.30% + 密度档位
          200/40 -> 160/35 -> 120/30。
合并规则：同日多条策略按 |全历史 Average| 最大者着色（R4）。
覆盖基金：103 支，全部满足 120/30、0.2%、55% 正式口径。

二、文件清单
-----------

1. v4_公司格式_最佳策略_全历史.xlsx
   全部基金最佳策略组合的逐日宽表，全历史版本。
   Sheet1=说明，Sheet2=基金数据，Sheet3=ETF外部示例。

2. v4_公司格式_最佳策略_冻结期.xlsx
   同上，只保留 2025-2026 冻结期。

3. v4_每基金策略映射.xlsx
   每支基金选定的策略清单，含全历史/冻结期统计。
   Sheet1=说明，Sheet2=数据。

4. v4_信号逐日明细_最佳策略.xlsx
   每条选定策略每次触发的逐日记录。
   Sheet1=说明，Sheet2=数据。

5. v4_strategy_mapping_complement_m30.csv
   策略映射表（机器可读版）。

6. v4_strategy_selection_complement_m30.csv
   每基金基准与选定策略合并后的统计。

7. 正式版说明.txt
   本文件。

三、行列含义
-----------

基金数据 Sheet：
- 第1-12行：公司13行统计头。
  第1行空白；第2-10行=Hit Ratio / Up Count / Down Count / Average /
  Max / Min / Count / Std / Sum；第11-12行空白。
- 第13行：列名；A列=日期，其余列=基金名称（代码）。
- 第14-16行：策略色块行，每行一条策略并填色。
- 第17行起：数据行，日期降序。
  基金列中日期格子按当天生效策略填色，格子内=触发日对应窗口的实际回报（%），
  空白=未触发。

ETF外部示例 Sheet：
- 第13行：A列=日期，其余列=20支ETF + VIX_Chg% + TNX_ChgBp。
- 第14-16行：ETF相关策略色块行。
- 第17行起：数据行；ETF列中触发策略的日期格子填色。

每基金策略映射 Sheet：
- 每行一条策略。
- 列含义：基金名称（代码）、策略序号、触发条件、预测窗口（日）、
  全历史平均回报（%）、全历史交易数、全历史命中率、
  冻结期平均回报（%）、冻结期交易数、冻结期命中率。

信号逐日明细 Sheet：
- 每行一次触发。
- 列含义：基金名称（代码）、触发条件、预测窗口（日）、日期、实际回报（%）。

四、策略命名规则
---------------

1. 单条件
   SPY_up / SPY_down / SPY_big_up / SPY_big_down / SPY_gt2 / SPY_lt-2
   SPY_bin_1_2（表示 SPY 涨幅落在 1%-2% 区间）

2. 双条件
   EEM_down_GDX_up = EEM 跌 且 GDX 涨

3. 三条件
   FXY_up_up_down_GDX_QQQ = FXY 涨、GDX 涨、QQQ 跌
   方向顺序对应条件里的三支 ETF。

4. 复合条件
   combo_QQQ_down__self_big_down = QQQ 跌 且 基金自身大跌
   复合条件用 __ 连接两个子条件。

5. 外部条件
   ext_vix_chg_ge5 = VIX 当日变化 >= 5%
   ext_vix_close_ge25 = VIX 收盘 >= 25
   ext_tnx_chgbp_le-10 = TNX 变化 <= -10bp

6. 自身条件
   self_up / self_down / self_big_up / self_big_down
   self_3up / self_3down / self_5up / self_5down

7. 预测窗口
   horizon=N 表示未来 N 个交易日；
   N>1 时回报 = 未来 N 日日平均回报。
