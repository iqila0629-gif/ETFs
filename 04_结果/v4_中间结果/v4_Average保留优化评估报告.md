# v4 Average 保留优化评估报告

> 日期：2026-08-07
> 问题：时间互补版交易更密，但合并 Average 从方案 A 的 0.3188% 降到 0.2431%

## 一、Average 下降的原因

对互补版 256 条策略做“边际贡献”分析：

| 指标 | 数值 |
|---|---:|
| 锚定策略自身 Average 中位数 | 0.4039% |
| 后加策略的新增独有交易日 Average 中位数 | 0.1664% |
| 后加策略中新增日 Average < 0.2% | 114 / 153 |
| 后加策略中新增日 Average < 0.3% | 148 / 153 |

原因很清楚：时间互补优先选择“新增交易日最多”的策略，但这些新增独有交易日大多是高质量策略没有覆盖的“剩余日”，平均回报偏低。合并 Average 是全部交易日的加权平均，加入大量低 Average 的新增日后，整体被拉低。

## 二、优化方法

### 方法 1：边际 Average 下限（推荐）

在互补选择时，只接受“新增独有交易日平均回报绝对值 >= 阈值”的策略。

```text
本轮测试阈值：0.20%
```

### 方法 2：合并 Average 下限

选择过程中要求合并后 Average 不低于锚定策略的 90% 或固定阈值（如 0.30%），不满足就不加该策略。

### 方法 3：加权目标

把贪心目标从“新增交易日最多”改成“新增交易日 × 新增日 Average”最大，直接优化贡献量。

## 三、0.20% 边际下限测试结果

| 指标 | 方案 A | 互补版 | 互补 + 0.20% 下限 |
|---|---:|---:|---:|
| 覆盖基金 | 103 | 103 | 103 |
| 整体达标 | 103 | 103 | 103 |
| 策略数 | 274 | 256 | 282 |
| 合并全历史 Average | 0.3188% | 0.2431% | 0.2848% |
| 合并全历史命中率 | 56.98% | 56.55% | 57.01% |
| 合并全历史交易数 | 570 | 1,251 | 1,088 |
| 合并冻结期 Average | 0.4657% | 0.4017% | 0.4168% |
| 合并冻结期交易数 | 81 | 128 | 133 |
| 吞没率中位数 | 34.7% | 9.6% | 9.1% |
| 单条全历史中位数 | 398 | 506 | 426 |

结论：

1. 加 0.20% 边际下限后，合并 Average 从 0.2431% 回到 0.2848%，几乎补回一半损失。
2. 交易数仍保持 1,088，明显高于方案 A 的 570，互补性基本保留（吞没率 9.1%）。
3. 命中率 57.01%，是几个版本里最高的。

## 四、建议

1. 如果既想要交易密度又想要 Average，推荐 **互补 + 0.20% 边际下限**。
2. 可以继续测试 0.25% / 0.30% 下限，预计 Average 更接近方案 A，但交易数会略降。
3. 若上司更看重 Average，保留方案 A；若更看重触发频率，用互补版。
