# v4 策略条数放宽测试报告

> 日期：2026-08-07
> 目的：测试放宽“每支基金允许的策略条数”是否能进一步优化
> 基础版本：m30（互补 + 边际 Average 下限 0.30% + 密度档位 200/40 -> 160/35 -> 120/30）

## 一、测试设定

选择逻辑保持不变，只把策略条数上限从 5 放宽到 8 和 10，并改为“在质量约束满足的前提下取最长策略组合”。

## 二、结果

| 指标 | m30（上限 5） | max8 | max10 |
|---|---:|---:|---:|
| 覆盖基金 | 103 | 103 | 103 |
| 整体达标 | 103 | 103 | 103 |
| 策略数 | 237 | 344 | 344 |
| 平均/基金 | 2.30 | 3.34 | 3.34 |
| 全历史 Average | 0.3706% | 0.3290% | 0.3290% |
| 全历史命中率 | 57.78% | 57.21% | 57.21% |
| 全历史交易数 | 712 | 745 | 745 |
| 冻结期 Average | 0.4531% | 0.4286% | 0.4286% |
| 冻结期交易数 | 105 | 121 | 121 |
| 吞没率中位数 | 2.8% | 20.6% | 20.6% |
| 吞没率 > 50% 的策略 | 19 | 85 | 85 |

## 三、结论

1. max8 和 max10 结果完全相同，说明没有基金需要超过 5 条策略。
2. 放宽策略条数只把交易数小幅提升（712 -> 745），但 Average 从 0.3706% 降到 0.3290%，命中率也下降。
3. 策略越多，同日重叠越多，吞没率从 2.8% 升到 20.6%，互补性明显变差。

**结论：放宽策略条数不能带来优化，m30 仍然是最佳正式版。**
