# v4 时间互补优化对比报告

> 日期：2026-08-07
> 目的：评估策略冲突吞没交易数，并测试“时间互补”筛查

## 一、问题确认

对方案 A（密度优化版）的 274 条选定策略做 R4 冲突分析：

| 指标 | 方案 A |
|---|---:|
| 策略平均吞没率中位数 | 34.7% |
| 吞没率 > 30% 的策略 | 138 / 274 |
| 吞没率 > 50% 的策略 | 111 / 274 |
| 完全没有独有交易日的策略 | 16 |
| 基金加权吞没率中位数 | 40.3% |

结论：**确实存在明显的冲突吞没**，部分策略大量交易日被更强策略覆盖，贡献被浪费。因此引入时间互补筛查是值得的。

## 二、时间互补方案

在方案 A 的密度分级基础上，选择逻辑改为：

1. 先用质量分选出一个锚定策略；
2. 后续每步优先选择“新增独有交易日最多”的策略；
3. 再按 3-5 条策略前缀检查质量约束；
4. 密度分级仍为 200/40 -> 160/35 -> 120/30。

## 三、效果对比

## 四、结论

1. 互补版把冲突吞没率从 34.7% 压到 9.6%，策略之间真正形成时间互补。
2. 合并后交易数大幅提升：全历史中位数 1,251、冻结期 128。
3. Average 和命中率略有下降，但仍满足 0.2% + 55% + 120/30 正式口径。
4. 如果更看重交易频率和策略利用率，推荐互补版；如果更看重 Average，保留方案 A 对照。
