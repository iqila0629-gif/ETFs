## 一、一句话结论

本项目用到的数据来自两个地方：

1. **Profunds 基金净值**：从 Profunds 官网（profunds.com）直接下载 `historical_nav.csv`，涵盖 129 支基金从 1997 年至今的每日 NAV。
2. **ETF 历史价格**：从 **Yahoo Finance v8 chart API** 下载，格式为 JSON，再转成 CSV。核心 19 支和扩展 57 支都使用这个方法。

**ETFDB 不可用**：它的价格表格由 JavaScript 动态加载，且"导出全部数据"属于付费功能，免费网页拿不到历史价格表。

## 二、Yahoo Finance v8 API 的完整原理

### 2.1 为什么选它

- **不需要 API Key**
- **不需要 crumb 认证**（v7 下载接口需要 crumb，且经常返回 401，本项目已验证失败）
- **直接返回 JSON**，包含从上市日到当天的全部日频数据
- 免费、稳定、数据含复权价

### 2.2 接口地址

```
https://query1.finance.yahoo.com/v8/finance/chart/{TICKER}?period1={起始时间戳}&period2={结束时间戳}&interval=1d
```

参数说明：

| 参数 | 含义 | 示例 |
|------|------|------|
| `TICKER` | 股票/ETF 代码 | `SPY`、`QQQ` |
| `period1` | 起始日期，Unix 秒时间戳 | `820454400` 代表 1996-01-01 |
| `period2` | 结束日期，Unix 秒时间戳 | 当前时间的 `int(time.time())` |
| `interval` | 频率 | `1d` 代表日线 |

### 2.3 返回的 JSON 结构

```json
{
  "chart": {
    "result": [
      {
        "timestamp": [Unix秒时间戳, ...],
        "indicators": {
          "quote": [
            {
              "open": [开盘价, ...],
              "high": [最高价, ...],
              "low": [最低价, ...],
              "close": [收盘价, ...],
              "volume": [成交量, ...]
            }
          ],
          "adjclose": [
            {
              "adjclose": [复权收盘价, ...]
            }
          ]
        }
      }
    ]
  }
}
```

### 2.4 时间戳转换

`timestamp` 是 Unix 秒（UTC），转成日期：

```python
import datetime
date_str = datetime.datetime.utcfromtimestamp(ts).strftime("%m/%d/%Y")
```

### 2.5 输出 CSV 格式

统一输出为：

```
Date,Open,High,Low,Close,Volume,Adj Close
01/02/1996,61.4062,62.1406,61.3438,62.1406,514400.0000,36.7188
...
```

日期格式统一为 `MM/DD/YYYY`，与 Profunds 的 `historical_nav.csv` 一致，方便后续日期对齐。

## 五、完整可复用的下载脚本

以下脚本可用于下载任意 ETF 列表的完整历史日线，就是本项目实际使用的方法。

```python
import json
import os
import time
import urllib.request
from http.cookiejar import CookieJar

# 要下载的 ETF 列表（按需修改）
TICKERS = ["SPY", "QQQ", "IWM", "TLT", "TIP", "EEM", "LQD", "HYG",
           "UUP", "SLV", "JNK", "GLD", "GDX", "XLV", "XLU", "XLE",
           "XLF", "XLK", "FXY"]

OUTPUT_DIR = r"C:\Users\vanessacen\Desktop\基金预测\raw_data\etfs"
os.makedirs(OUTPUT_DIR, exist_ok=True)

headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                  "AppleWebKit/537.36 Chrome/125",
    "Accept": "application/json,text/plain,*/*",
}
jar = CookieJar()
opener = urllib.request.build_opener(urllib.request.HTTPCookieProcessor(jar))

# 1996-01-01 作为起点，覆盖绝大多数 ETF 上市日
PERIOD1 = 820454400
PERIOD2 = int(time.time())

for ticker in TICKERS:
    url = (f"https://query1.finance.yahoo.com/v8/finance/chart/{ticker}"
           f"?period1={PERIOD1}&period2={PERIOD2}&interval=1d")
    try:
        req = urllib.request.Request(url, headers=headers)
        resp = opener.open(req, timeout=20)
        data = json.loads(resp.read().decode("utf-8"))
        result = data["chart"]["result"][0]
        ts = result["timestamp"]
        quotes = result["indicators"]["quote"][0]
        adj = result["indicators"].get("adjclose", [{}])[0].get("adjclose", [])

        def val(arr, i):
            return f"{arr[i]:.4f}" if i < len(arr) and arr[i] else ""

        csv_lines = ["Date,Open,High,Low,Close,Volume,Adj Close"]
        for i in range(len(ts)):
            d = time.strftime("%m/%d/%Y", time.gmtime(ts[i]))
            csv_lines.append(
                f"{d},{val(quotes.get('open', []), i)},"
                f"{val(quotes.get('high', []), i)},"
                f"{val(quotes.get('low', []), i)},"
                f"{val(quotes.get('close', []), i)},"
                f"{val(quotes.get('volume', []), i)},"
                f"{val(adj, i)}"
            )
        with open(os.path.join(OUTPUT_DIR, f"{ticker}.csv"),
                  "w", encoding="utf-8") as f:
            f.write("\n".join(csv_lines))
        print(f"{ticker}: {len(ts)} rows")
    except Exception as e:
        print(f"{ticker}: FAIL - {e}")
    time.sleep(0.2)  # 避免请求过频被限制
```

运行方式（Windows）：

```powershell
python download_etfs.py
```

或使用项目内已捆绑的 Python：

```powershell
& "C:\Users\vanessacen\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" download_etfs.py
```

1. 修改脚本里的 `TICKERS` 列表和 `OUTPUT_DIR`。
2. 如果需要增量更新（只补最近几天），把 `PERIOD1` 改成上次数据的最后日期，例如：

```python
PERIOD1 = int(datetime.datetime(2026, 8, 4).timestamp())
```

3. 运行脚本，新文件会覆盖旧文件。
4. 更新后检查：
   - 最后一行日期是否为最新交易日
   - 行数是否增加
   - 是否有空值或断档

## 七、注意事项

1. **频率控制**：请求之间加 `time.sleep(0.2)`，不要并发几十个请求，否则容易被 Yahoo 限流。
2. **User-Agent**：必须带浏览器 UA，默认 urllib UA 容易被拒。
3. **ETFDB**：价格导出是付费功能，免费网页只有基本面信息，不适合作为历史价格来源。
4. **Yahoo v7 下载接口**：`/v7/finance/download/` 需要 crumb，本项目实测返回 401，不推荐。
5. **复权价**：`adjclose` 已包含分红/拆股调整。做日回报分析建议使用 `Adj Close`，做纯价格分析可用 `Close`。
6. **日期格式**：统一用 `MM/DD/YYYY`，与 Profunds 数据一致，避免后续对齐出错。

- 日期范围：1997-10-30 至 2026-07-27

### 8.3 ProFunds Adjusted Close（总回报口径，2026-08-05 新增）

官网 NAV 只反映价格回报，不含分红/资本利得再投资。为得到总回报口径，
改用 Nasdaq 官方接口下载每支基金的 `Adjusted Close`：

```
https://api.nasdaq.com/api/quote/{TICKER}/historical?assetclass=mutualfunds&fromdate=1990-01-01&todate=YYYY-MM-DD&limit=9999
```

- 返回字段包含 `Close/Last` 和 `Adjusted Close`
- 129 支基金全部下载成功，存于 `raw_data/profunds/adj_close_nasdaq/{TICKER}.json`
- 覆盖范围：多数基金 2005 年起，部分基金可回溯到 1998 年，截止 2026-08-04
- 注意：1997-2005 的基金调整价部分缺失，如需补齐需另找总回报数据源
- 后续分析应使用 Adjusted Close 计算基金日回报（价格回报与总回报的差异见上面的 Adj Close 说明）

## 十、常见问题

### Q1：为什么扩展 ETF 之前只有 2016 年之后的数据？

因为当时换用了 Nasdaq 历史接口，该接口默认只返回约 10 年数据（2,513 行）。已用 Yahoo v8 API 重新下载修复。

### Q2：下载时返回 403 / 401 怎么办？

- 检查是否带了浏览器 User-Agent
- 增加请求间隔
- 换 `query2.finance.yahoo.com` 试试
- 等待几分钟再试，Yahoo 可能临时限流

### Q3：`adjclose` 为空怎么办？

当前核心 19 支和扩展 57 支均实测无空值。若个别品种没有复权数据，
脚本已处理为空值，分析时优先用 `Close` 并单独标注。

### Q4：如何确认数据下载完整？

用最后一节脚本打印 `len(ts)`、首个日期和最后日期，与本节表格对照即可。
