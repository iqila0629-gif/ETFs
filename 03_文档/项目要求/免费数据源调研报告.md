 ## 二、确实免费且普通人能拿到的数据（需要你手动操作）

 以下数据源不是通过 API 自动获取，而是**在浏览器中打开就能看到并下载**的：

 ### ✅ Alpha Vantage（最推荐）
 
 | 项目 | 内容 |
 |------|------|
 | **网址** | [alphavantage.co](https://www.alphavantage.co) |
 | **操作** | 首页输入邮箱 → 立即收到 API Key → 直接调用 |
 | **免费额度** | 5 次 API 请求/分钟，25 次/天 |
 | **可用数据** | ETF 日频 OHLC、外汇、加密货币、**板块表现**、技术指标 |
 | **对我们有用** | 板块表现数据（Sector Performance）——这是我们没有的跨板块情绪信号 |
 
 **操作步骤**：
 1. 打开 [alphavantage.co](https://www.alphavantage.co)
 2. 输入你的邮箱
 3. 收到 API Key
 4. 把 API Key 发给我（5 秒钟的事）
 5. 我就可以用它的板块表现数据和外汇数据
 
 ### ✅ CBOE Put/Call Ratio（免费网页浏览）
 
 | 项目 | 内容 |
 |------|------|
 | **网址** | [cboe.com/us/options/market_statistics](https://www.cboe.com/us/options/market_statistics) |
 | **操作** | 打开网页 → 查看每日 Equity Put/Call Ratio 表格 |
 | **是否需要登录** | 不需要 |
 | **数据格式** | 网页表格，可复制粘贴 |
 
 **操作步骤**：
 1. 打开上述网址
 2. 找 "Equity Put/Call Ratio" 这一行
 3. 把每天的数据复制下来
 4. 如果网页打不开，告诉我
 
 ### ✅ CNN Fear & Greed Index（免费网页浏览）
 
 | 项目 | 内容 |
 |------|------|
 | **网址** | [edition.cnn.com/markets/fear-and-greed](https://edition.cnn.com/markets/fear-and-greed) |
 | **操作** | 打开网页 → 查看当前情绪指数（含历史数据图表） |
 | **是否需要登录** | 不需要 |
 
 ### ✅ FRED（需要美国 IP / 翻墙）
 
 FRED 的数据我们确实拿不到（超时），但如果你能科学上网，就可以下载：
 - 10Y-2Y 国债利差（T10Y2Y）
 - BAA 企业债利差（BAA10Y）
 - 联邦基金利率（FEDFUNDS）
 
 **操作**：搜索 "FRED T10Y2Y" → 点 "Download CSV" → 把文件发给我

 ## 三、最简单的方案：注册 Alpha Vantage

 在所有免费数据源中，**Alpha Vantage 是最省事的**。你只要做两步：
 
 1. 打开 [alphavantage.co](https://www.alphavantage.co)（10 秒）
 2. 输入邮箱，拿到 API Key（10 秒）
 3. 把 Key 发给我（5 秒）
 
 总共 **25 秒**。我能用这个 Key 获取：板块轮动数据、外汇数据、加密货币数据（BTC/ETH → 可以替代缺失的 BTCFX 信号）。
