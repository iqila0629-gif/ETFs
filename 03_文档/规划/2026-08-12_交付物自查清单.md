# 交付物自查清单

日期：2026-08-12

## 一、近期实际犯过的错误（已复盘）

1. 外部数据示例日期与 ETF 数据不一致，导致示例出现 `#VALUE!`；已改为从数据文件读取并补齐到 8/7。
2. 外部 OHLC 合并脚本重复运行会覆盖成空列（非幂等）；已改为先删除旧列再合并。
3. 统计头 Average/Max/Min 对所有列统一设置成百分比，价格、Volume、相关系数显示成 `%`；已按单位映射修正。
4. 策略表头不管 horizon 是多少都写“买基金第二天”，horizon=2/3/5 的策略会误导；已改为按 horizon 显示“买基金后 N 日平均回报”。
5. 源数据存在 Adj Close 阶跃异常（URPSX、UAPIX、UCPIX、BITIX 等）；已清洗 adjustedClose 并重新生成文档。
6. 只改了展示文档，没有同步“最新结果”交付包和建模 panel，属于“改一个产物、漏关联产物”的典型错误。

## 二、可能还有风险的检查项

### 数据清洗
- 清洗只处理了 JSON 的 `adjustedClose`，`close` 字段仍是脏值。如果吕先生或后续流程用 `close`，会再次看到异常。需要确认是否也清洗 `close`，或明确约定只用 `adjustedClose`。
- `panel_fund_returns_adj.csv` 仍是未清洗数据；策略映射统计也是基于“截断 ±50%”的旧 panel。清洗后文档的统计头与映射表的 `full_avg/frozen_avg` 数值口径不一致，交付时要说明，或从头重跑建模。
- 复权断层按跳变因子整体调整历史前值，需抽查因子是否重复叠加、是否误伤真实行情（例如 2025-04-09 的 20%-28% 属于真实行情，不应被清洗）。

### 公式与口径
- horizon>1 的目标公式写成 `AVERAGE(DA38:DA37)` 反序范围，Excel 能计算，但可读性差；建议统一改成 `AVERAGE(DA37:DA38)`。
- 统计头第 2 行 Hit Ratio 对价格列也显示百分比，语义上可解释，但要确认上级接受。
- 空列或全空数据列的统计头仍可能出现 `#DIV/0!`（按之前要求保留原公式，不做 IFERROR）。

### 格式
- 价格列数据区目前是 General，统计头是 `0.0000`，视觉精度可能不一致，可统一成 `0.0000`。
- Volume 数据区是 General，统计头是 `#,##0`，整数显示基本一致，可统一。

### 交付
- `最新结果/` 交付包还没同步清洗后的工作簿、新增“基金基础数据”Sheet 和说明；打包前需要复制。
- 大文件（结果 xlsx、清洗后 JSON）都在 `.gitignore`，换机器或克隆后需要重新生成，不能只靠 git 恢复。

### 脚本与日志
- `clean_profunds_outliers.py` 的日志中，level_shift 的 `new_close` 语义容易误解：它指跳变日本身清洗后不变，实际变化在历史前值。建议日志补充 factor 和受影响日期范围。
- `build_v4_m30_full_newformat.py` 有未使用的 `import os`，可顺手清理。

## 三、每次交付前必跑检查

1. 清洗可复现：运行 `clean_profunds_outliers.py` 后，全样本日回报绝对值 >= 50% 的单元格应为 0。
2. Sheet 结构：全历史/25-26 均应有 `说明`、`数据`、`基金基础数据` 三个 Sheet。
3. 行对齐：两个 Sheet 的 A16 应为同一最新日期（如 8/4），并抽查中间日期行号一致。
4. 表头：73 条 horizon>1 策略表头含“平均回报”，164 条 horizon=1 为“买基金第二天”，数量与映射表一致。
5. 单位抽查：XLC Open Max 不是百分比；Volume 不是百分比；TNX_ChgBp 是 bp；StkBonCorr、VIX_TNX_Ratio 是普通小数。
6. 公式抽查：策略目标区间与 horizon 一致；CreditSpread=HYG回报-TLT回报、VIX_TNX_Ratio=VIX Close/TNX Close 等派生公式引用正确。
7. 数据源：结果文档必须由 `01_数据/processed_returns/profunds_adj_cleaned/` 生成，不是原始 JSON。
8. git 纪律：只提交脚本、报告、小 CSV；不提交大 xlsx 和 100MB 级清洗 JSON；大文件在磁盘保留并在说明中写清楚。

## 四、结论

近期错误的共性是把“一个统一规则”套到所有列、所有策略，或者改了数据后没有同步关联产物。当前正式文档已修复统计头单位和 horizon 表头，并新增基础数据 Sheet；仍待确认：是否清洗 `close` 字段、是否重跑建模、是否同步最新结果交付包。
