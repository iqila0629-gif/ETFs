# 研究规划（可实施版）：ETF 今日涨跌 → ProFunds 明日涨跌与平均回报

> 日期：2026-07-31
> 依据：上司指示——"假设 SPY 今天涨了、QQQ 今天涨了，用历史数据预测 ProFunds 明天是涨还是跌，涨跌平均回报是多少"

---

## 一、目标与验收标准

**目标**：以"今日 ETF 涨跌"为触发条件，用历史数据回答：

1. 该条件下，明天基金更可能涨还是跌？
2. 明天上涨时平均回报多少？明天下跌时平均回报多少？

**验收标准**：对每一支达标基金，输出预测列的平均回报（公司 13 行格式第 5 行 Average）满足：

- `>= +0.2%`，或
- `<= -0.2%`

全部输出文件：

- 保留公司 13 行固定头部
- 数据按日期降序
- 预测日 = 条件发生后的次日（t 日 ETF 数据 → t+1 日基金回报）

---

## 二、数据与口径

### 2.1 输入数据

| 文件 | 内容 | 读取方式 |
|------|------|----------|
| `processed_returns/combined_profunds_nav.csv` | 129 支基金 NAV，7,241 个交易日 | `pd.read_csv(..., skiprows=12)` |
| `processed_returns/combined_etf_returns.csv` | 19 支 ETF 日回报，7,691 个交易日 | `pd.read_csv(..., skiprows=12)` |

预处理：

1. NAV 表转基金日回报：`fund_ret = NAV.pct_change()`（按日期升序计算后再转回降序）
2. 两张表按日期 inner join，得到共同交易日 7,219 天
3. 构造标签：`tomorrow_return[t] = fund_ret[t+1]`
4. 检查缺失：单支基金样本少于 1,000 天的标记为低样本，不进入主筛选

### 2.2 统计口径（每支基金 × 每个条件）

设条件为 C（例如 "SPY 今日涨"），事件日集合为 `{t | C(t)=True}`，且 t+1 日基金回报存在：

| 指标 | 公式 |
|------|------|
| 事件天数 N | `count(t)` |
| 明日上涨次数 | `count(tomorrow_return > 0)` |
| 明日下跌次数 | `count(tomorrow_return < 0)` |
| 明日上涨概率 P_up | `上涨次数 / N` |
| 明日下跌概率 P_down | `下跌次数 / N` |
| 涨时平均回报 Avg_up | `mean(tomorrow_return | tomorrow_return > 0)` |
| 跌时平均回报 Avg_down | `mean(tomorrow_return | tomorrow_return < 0)` |
| 条件期望回报 E | `mean(tomorrow_return)`，即 P_up×Avg_up + P_down×Avg_down |

`tomorrow_return == 0` 的天数计入 N，但不计入涨/跌次数，也不进入 Avg_up/Avg_down。

## 三、条件定义（逐步扩展）

### 3.1 单条件（第一版先做这个）

对每支 ETF 定义四类条件：

1. 涨：`ETF_ret > 0`
2. 跌：`ETF_ret < 0`
3. 大涨：`ETF_ret >= +1%`
4. 大跌：`ETF_ret <= -1%`

共 `19 支 ETF × 4 类 = 76 个条件`，对 129 支基金全量扫描。

### 3.2 双条件（对应上司示例）

优先验证四组 SPY × QQQ 组合：

| 组合 | 条件 |
|------|------|
| 双涨 | SPY 涨 且 QQQ 涨 |
| 双跌 | SPY 跌 且 QQQ 跌 |
| 涨跌分歧 | SPY 涨 且 QQQ 跌 |
| 跌涨分歧 | SPY 跌 且 QQQ 涨 |

再扩展其他高相关 ETF 组合（如 SPY×XLF、QQQ×XLK）。

### 3.3 一致性条件

- 多数看涨：当天上涨 ETF 数量 >= 12/19
- 多数看跌：当天下跌 ETF 数量 >= 12/19
- 全线上涨：19 支 ETF 全部上涨
- 全线下跌：19 支 ETF 全部下跌

### 3.4 幅度分档（对通过初筛的 ETF）

以 SPY 为例：

| 档位 | 条件 |
|------|------|
| A | 0% < ret <= 0.5% |
| B | 0.5% < ret <= 1% |
| C | 1% < ret <= 2% |
| D | ret > 2% |

跌幅同理取负值分档。目的是找出"幅度越大、明日信号越强"的档位。

---

## 四、决策规则

对每个（基金，条件）组合，先算统计量，再按以下规则决策：

| 情形 | 条件 | 决策 | 输出预测值 |
|------|------|------|------------|
| 看涨 | N >= 200 且 P_up >= 0.55 且 Avg_up >= +0.2% | 预测涨 | `Avg_up` |
| 看跌 | N >= 200 且 P_down >= 0.55 且 Avg_down <= -0.2% | 预测跌 | `Avg_down` |
| 不操作 | 其他情况 | 不输出 | 空 |

规则必须满足两个同时条件：**方向概率超过 55%** 且 **该方向平均回报达到 0.2%**。只满足一个不算达标，避免"方向对但幅度不够"和"幅度够但方向随机"。

第一版用固定阈值；验证阶段再测试：

- `P >= 0.53 / 0.55 / 0.58 / 0.60`
- `N >= 100 / 200 / 300`
- 幅度阈值 `0.15% / 0.20% / 0.25%`

## 五、分阶段实施

### 阶段 1：数据管道（0.5 天）

新建目录 `analysis_results/event_study/`，写 `build_panel.py`：

1. 读取两张合并表（`skiprows=12`）
2. 生成基金日回报表 `panel_fund_returns.csv`
3. 生成 ETF 日回报表 `panel_etf_returns.csv`
4. 日期对齐、升序排列、构造 `tomorrow_return`
5. 输出数据质量报告：行数、缺失率、每支基金样本数

检查点：共同交易日 = 7,219，129 支基金，19 支 ETF。

### 阶段 2：单条件全量扫描（1-2 天）

写 `scan_single_events.py`：

1. 生成 76 个单条件
2. 对每个条件 × 129 支基金计算 N / P_up / P_down / Avg_up / Avg_down / E
3. 输出 `event_summary_single.csv`
4. 初筛并输出 `shortlist_single.csv`：
   - N >= 200
   - |E| >= 0.15%
   - P_up 或 P_down >= 0.53
5. 按基金类型（1x / 杠杆 / 反向 / 板块）分组汇总

交付物：`event_summary_single.csv` + 短名单。

### 阶段 3：双条件与一致性条件（1-2 天）

写 `scan_pair_events.py`：

1. 计算 3.2 的 SPY×QQQ 四组合
2. 计算 3.3 的一致性条件
3. 与单条件结果对比：组合条件是否提升 P_up / Avg_up
4. 合并输出 `event_summary_pair.csv`，更新短名单

检查点：上司示例"SPY 涨 且 QQQ 涨"必须单独列出结果。

### 阶段 4：幅度分档（1 天）

写 `scan_magnitude_bins.py`：

1. 对 SPY、QQQ、XLF、XLK 等通过初筛的 ETF 分档
2. 输出 `event_summary_bins.csv`
3. 找出信号单调性最强的档位（如 D 档 P_up >= 0.60）

### 阶段 5：生成预测 CSV（2 天）

写 `generate_predictions.py`：

1. 按第四章规则对短名单生成预测
2. 每个（基金，条件）输出一个标准 13 行 CSV：
   - 第 2-10 行统计块按输出列自动重算
   - 数据行：条件发生的日期（降序），预测值 = Avg_up 或 Avg_down
3. 自动校验每个文件的 Average 是否达到 `+0.2%` / `-0.2%`
4. 输出 `达标汇总.csv`：基金、条件、N、P、Avg_up、Avg_down、Average、预测数、状态

输出目录：`analysis_results/event_study/predictions/`

### 阶段 6：样本外验证（2-3 天）

写 `walk_forward.py`：

1. 五段验证：2009-2012 / 2013-2016 / 2017-2020 / 2021-2023 / 2024-2026
2. 每段用段前历史估计统计量，段内逐日验证（expanding window，禁止未来信息）
3. 只保留满足以下条件的组合：
   - 全期 Average 达标
   - 至少 3/5 段达标
4. 参数扰动：P 阈值、N 阈值、幅度阈值小幅变化，结果仍达标
5. ETF 子集测试：去掉任意 2 支 ETF 后仍达标
6. 输出 `stability_report.csv`

### 阶段 7：交付（0.5 天）

1. 最终达标预测 CSV 复制到 `analysis_results/final_outputs/`
2. 更新工作日报
3. 写研究小结：哪些基金、哪些条件、达到什么 Average

## 八、风险与应对

| 风险 | 应对 |
|------|------|
| 条件事件太少（如大跌档） | N >= 200 下限；不达标就并入更宽条件 |
| 概率接近随机（50% 上下） | 用 55% 概率门槛，宁可不操作 |
| 1x 基金幅度不足 | 接受"该基金不可达标"，只保留达标基金 |
| 全样本达标但分段失效 | 5 段验证 + 至少 3/5 段达标 |
| 未来信息泄露 | 预测只用 t 日及之前数据；t+1 只做标签 |
| 输出 Average 不达标 | `generate_predictions.py` 内置自动校验，不达标不输出 |
