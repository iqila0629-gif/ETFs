 ## 二、测试结果

 ### 与 Profund 次日回报的相关性（Top 15）

 | 特征 | Profund | 相关系数 | 方向准确率 | Avg预测 |
 |------|---------|---------|-----------|--------|
 | VIX_Close | ULPIX (2x SPY) | **-0.110** | 54.0% | 0.075% |
 | VIX_Close | ULPSX (-2x SPY) | -0.110 | 53.9% | 0.070% |
 | SPY | ULPIX | -0.104 | 48.7% | 0.073% |
 | VIX_Close | LGPIX (1x) | -0.103 | **55.1%** | 0.045% |
 | VIX_Close | UOPIX (2x Nasdaq) | -0.100 | **55.4%** | **0.117%** |
 | VIX_20dVol | ULPIX | -0.099 | 54.1% | 0.075% |
 | VIX_Close | FNPIX (1.5x Fin) | -0.097 | 52.4% | 0.046% |
 | VIX_20dVol | UOPIX | -0.093 | **55.4%** | **0.119%** |
 | SPY | LGPIX | -0.102 | 48.4% | 0.043% |
 | VIX_5dChg | UOPIX | -0.085 | 45.8% | 0.118% |
 | USDGoldRatio | UOPIX | -0.054 | 49.0% | 0.115% |

 ### 关键发现

 1. **VIX 是比 SPY 更好的方向预测器**：VIX_Close 的方向准确率（54-55%）显著高于 SPY（47-49%）。当 VIX 今天上涨（市场恐慌），明天 Profund 下跌的概率达到 55%。
 2. **两种特征的绝对值最大**：VIX_Close（|corr| ≈ 0.10-0.11）和 VIX_20dVol（|corr| ≈ 0.09-0.10），远好于其他派生特征。
 3. **UOPIX（2x Nasdaq-100）预测效果最好**：Average 预测值达到 0.119%，是所有测试中的最高值。
 4. **派生特征整体偏弱**：CreditSpread、JNKSpread、SectRotation 等特征的 |corr| < 0.05，预测力有限。
 5. **0.2% 门槛仍未达到**：最接近的是 VIX_20dVol→UOPIX 的 0.119%，约为目标的一半。

 ## 三、还需要哪些数据？

 以下数据源有望提供**独立于价格数据的信息**，突破当前瓶颈：

 ### 优先级 1：宏观事件预测概率（最有希望）

 | 数据 | 平台 | 为什么需要 | 获取难度 |
 |------|------|-----------|---------|
 | **美联储利率决策概率** | Kalshi | 直接影响股市方向（VIX 的先行指标）| 需注册账号 + API Key |
 | **CPI/通胀数据预测** | Kalshi | 通胀是影响利率和股市的核心宏观变量 | 同上 |
 | **非农就业预测** | Kalshi | 就业数据发布日市场波动最大 | 同上 |
 | **标普500点位预测** | Kalshi | 对 Profund 预测有直接参考价值 | 同上 |

 **为什么这些特别重要**：预测市场概率反映的是**集体智慧对未来事件的预期**，这与历史价格数据完全不同的信息维度。即使 Kalshi 日频概率变化很小，它的水平值（如"降息概率 65%"）本身就包含了市场对宏观环境的综合判断。

 ### 优先级 2：情绪与流量指标

 | 数据 | 来源 | 为什么需要 | 获取难度 |
 |------|------|-----------|---------|
 | **Put/Call Ratio** | CBOE | 期权市场的情绪极端信号 | 公开数据，可爬取 |
 | **CNN Fear & Greed Index** | CNN Business | 综合情绪指标（7个因子合成）| 公开数据，可爬取 |
 | **AAII 投资者情绪调查** | AAII | 散户情绪的多空比例 | 每周免费发布 |
 
 ### 优先级 3：替代数据（另类数据）

 | 数据 | 说明 | 获取难度 |
 |------|------|---------|
 | **Polymarket 政治/经济事件概率** | 全球最大的去中心化预测市场 | 需要账号 + 认证 |
 | **ETF 资金流数据** | 每日 ETF 的净流入/流出 | Bloomberg/Refinitiv 付费 |
 | **COT 持仓报告** | CFTC 每周发布的期货持仓数据 | CFTC 官网免费但有延迟 |

 ## 四、你可以怎么帮我获取这些数据？

 ### 方式 A：Kalshi 注册 + API Key（推荐，最有用）

 **步骤**：
 1. 访问 [kalshi.com](https://kalshi.com) 注册一个账号（用你的公司邮箱）
 2. 完成身份验证（KYC，因为他们受 CFTC 监管）
 3. 登录后进入 Settings → API → 生成一个 API Key
 4. 把 API Key 和账号信息给我

 **我拿到 API Key 后能做**：
 - 下载美联储利率、CPI、就业数据等所有事件的**完整历史概率数据**
 - 将这些概率作为新特征加入模型
 - 直接评估预测市场概率对 Profund 的预测力

 **预计耗时**：注册 10 分钟，KYC 审核可能需要 1-3 天

 ### 方式 B：Polymarket 账号

 **步骤**：
 1. 访问 [polymarket.com](https://polymarket.com)
 2. 连接钱包（MetaMask 或其他以太坊钱包）
 3. 可能需要 VPN（美国 IP 被限制）

 **注意**：Polymarket 对非美国用户是开放的。如果无法访问，可以跳过。

 ### 方式 C：手动导出数据（最直接）

 如果 API 注册太麻烦，也可以手动方式：
 1. 打开 Kalshi 网页，找到你关心的市场（如"FOMC Interest Rate Decision"）
 2. 查看历史价格图表
 3. 截图或手动记录关键时间点的概率值
 4. 按日期整理成 CSV 发给我

 **手动整理格式示例**：
 ```
 Date,FedRateCut25bp_Prob,CPI_Above3pct_Prob
 07/01/2026,0.65,0.32
 07/02/2026,0.63,0.35
 ...
 ```
