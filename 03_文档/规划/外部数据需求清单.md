 ## 二、最有价值的外部数据（按优先级）

 ### 1. CBOE Put/Call Ratio（期权多空比）

 | 项目 | 内容 |
 |------|------|
 | **为什么有用** | 期权市场的多空比例直接反映机构/专业交易者的情绪，与 VIX（价格波动）相关性低，是独立信号 |
 | **获取方式** | CBOE 网站免费公布 / Bloomberg `PCR` / Wind 终端 |
 | **数据格式** | 日频，一个比率值（>1 = 看跌多，<1 = 看涨多） |
 | **预期准确率** | ~54-56%（如果对极端值做阈值过滤）|

 ### 2. NYSE Advance-Decline Line（涨跌线）

 | 项目 | 内容 |
 |------|------|
 | **为什么有用** | 市场广度——参与上涨的股票数量 vs 下跌数量。当 SPY 涨但 AD 线跌，是背离信号（SentimenTrader 的核心逻辑）|
 | **获取方式** | Bloomberg `AD` / Yahoo Finance `^NYAD` 可能需要验证 |
 | **数据格式** | 日频，累积差值（或每日涨跌家数）|
 | **预期准确率** | ~53-55%（广度背离信号）|

 ### 3. VIX Futures Term Structure（VIX 期货期限结构）

 | 项目 | 内容 |
 |------|------|
 | **为什么有用** | VIX 期货的 Contango/Backwardation 状态比 VIX 本身更领先。当 VIX 现货 < 期货（Contango）→ 市场平静；VIX 现货 > 期货（Backwardation）→ 恐慌 |
 | **获取方式** | CBOE 网站 / Bloomberg `VX1`, `VX2` / 或直接用 `UVXY`/`SVXY` ETF 替代 |
 | **数据格式** | 日频，两个期货合约价格的比值或差值 |
 | **预期准确率** | ~54-56%（比 VIX 本身更稳定）|

 ### 4. 信用利差（High-Yield Spread）

 | 项目 | 内容 |
 |------|------|
 | **为什么有用** | 我们用 HYG 和 JNK 计算过派生信用利差，但原始的高收益债利差（HYG 收益率 - 国债收益率）更纯粹 |
 | **获取方式** | Bloomberg `OAS` / FRED `BAMLH0A0HYM2` / 我们已有 HYG 和 TLT 可近似 |
 | **数据格式** | 日频，利差基点（bp）|
 | **预期准确率** | ~52-54%（已验证，我们的派生版本效果一般）|

 ### 5. 经济意外指数（Citigroup ESI）

 | 项目 | 内容 |
 |------|------|
 | **为什么有用** | 衡量经济数据超出/低于预期的程度。当 ESI 上升，风险偏好上升→利好股市。这是宏观层面的独立信号 |
 | **获取方式** | Bloomberg `CESIUSD` / 或手动跟踪重要经济数据发布 |
 | **数据格式** | 周频或日频，一个指数值 |
 | **预期准确率** | ~53-55%（宏观层信号，与价格数据低相关）|

 ### 6. 纽交所保证金债务（NYSE Margin Debt）

 | 项目 | 内容 |
 |------|------|
 | **为什么有用** | 散户杠杆水平——保证金债务极高时 → 市场过热；保证金债务下降 → 去杠杆 → 市场承压 |
 | **获取方式** | FINRA 网站每月公布 / Bloomberg |
 | **数据格式** | 月频，总债务金额（十亿）|
 | **预期准确率** | ~52-54%（低频但信号强）|
