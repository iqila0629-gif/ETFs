# v4 m30 交付格式修改规划

> 日期：2026-08-10
> 范围：只改 m30 正式版成果，其余版本一律不动
> 目标：让合并策略效果更可读、可核对、可追溯，方便吕先生直接判断是否真实可靠

## 一、需求拆解

根据上司反馈，需要做以下调整：

1. 每支基金除了“合并效果”一列外，增加单独策略效果列：
   在合并列前面插入策略列，每个策略一列，作为对比参考。

2. 把基础数据放到最左边：
   每一行对应一个日期，基础数据（基金回报、ETF 回报、外部数据）放在最左，
   策略列和合并列用 Excel 公式计算，不用写死的数值。

3. 日期格式改为 YYYY/MM/DD。

4. 策略条件写清楚阈值，例如：
   - `EEM_down_GDX_up` 写成 `EEM<0 且 GDX>0，买基金第二天`
   - 明确 down 是 `<0`，big_down 是 `<=-1%`，gt2 是 `>2%` 等。

5. 只修改 m30 正式版，其他版本保留不动。

## 二、目标版式

```text
A          B...D         E...G          H       I      J      K
日期       基础数据区      每支基金占 4 列
           (ETF/基金/外部)  策略1  策略2  策略3  合并效果
-----------------------------------------------------------------
2026/08/04  ...          公式   公式   公式   公式
2026/08/03  ...          公式   公式   公式   公式
```

每支基金：

- 前面插入 N 列策略列（N = 该基金实际策略数，通常 1-5）。
- 最后一列是合并效果列（原合并列）。
- 策略列效果不佳也没关系，保留在旁边作参考。

公司 13 行统计头保留，统计公式范围覆盖策略列和合并列。

## 三、基础数据区

放在最左边，一列一个数据源：

- 日期列。
- 20 支 ETF 日回报（原始19 + XLC）。
- 103 支已覆盖基金的日回报（用于计算策略实际回报）。
- 策略用到的外部数据列（VIX/TNX 等）。

如果全部放进去列数太多，先按“被 m30 策略实际使用”的数据源生成，减少冗余。

## 四、Excel 公式方案

### 4.1 策略列

每个策略列在触发日显示“次日实际回报”，未触发留空。

公式逻辑：

```text
=IF(条件成立(基于基础数据列), 基金次日回报, "")
```

示例：

```text
策略：EEM<0 且 GDX>0，买基金第二天
=IF(AND(EEM列>0? 注意方向, GDX列>0), 基金次日回报单元格, "")
```

日期保持降序（公司格式），因此“次日”是数据区的上一行。

### 4.2 合并列

合并列按 R4 规则：

- 当天有多条策略触发时，取 |全历史 Average| 最大的策略回报；
- 只有一条触发时取该策略回报；
- 未触发留空。

公式建议用嵌套 IF 或 CHOOSE + MATCH 实现，具体公式在实现阶段确定。

### 4.3 公式可见性

- 打开 Excel 能看到公式，而不是写死的数字。
- 公式引用最左侧基础数据列，便于抽查某个日期是否计算正确。

## 五、策略命名与阈值说明

在 Excel 策略列名和说明 Sheet 中写清楚：

| 写法 | 含义 |
|---|---|
| SPY>0 | SPY 当日涨 |
| SPY<0 | SPY 当日跌 |
| SPY>=1% | SPY 大涨（big_up） |
| SPY<=-1% | SPY 大跌（big_down） |
| SPY>2% | 涨超 2%（gt2） |
| SPY<-2% | 跌超 2%（lt-2） |
| EEM<0 且 GDX>0 | 双条件，同时成立 |
| EEM>0 且 JNK>0，买基金第二天 | 双条件 + 执行时点 |

所有策略统一在名称里带“买基金第二天”，表示信号用 T 日数据、目标取 T+1 日回报。

## 六、实施步骤

1. 新增/改造 m30 交付生成脚本：
   - 只处理 m30_v2。
   - 输出“基础数据区 + 策略列 + 合并列”的新版式。
2. 日期格式改为 YYYY/MM/DD。
3. 策略名称转换为可读格式，并附阈值说明。
4. 生成一个“两基金示例”供审批，确认版式和公式后再全量生成。
5. 全量生成 m30 正式版，覆盖 `最新结果/关键成果` 和 `04_结果/v4_正式版_m30_v2` 的副本。
6. 同步更新 Excel 说明 Sheet 和 `说明.txt`。
7. 用 Excel 打开抽查：
   - 公式能计算；
   - 触发日、回报与脚本输出一致；
   - 统计头公式正确。

## 七、验收标准

1. 每支基金：N 个策略列 + 1 个合并列。
2. 最左侧是基础数据，日期降序，格式 YYYY/MM/DD。
3. 策略列和合并列全部是公式，不是写死数值。
4. 合并列与当前 m30 结果一致（Average、命中率、交易数）。
5. 策略名写清阈值和“买基金第二天”。
6. 其余版本（原版、方案A、m20、m25、互补版、全信号）不修改。

## 八、风险与待确认

1. 全量公式可能让 Excel 变大、打开变慢，先做两基金示例确认可接受。
2. 基础数据列范围待确认：全部 129 支基金，还是只放已覆盖的 103 支。
3. 日期降序下“次日”是上一行，公式写法会在示例里明确。
4. 合并列公式复杂度较高，示例审批时确认逻辑。
5. 统计头保留公司 13 行格式，公式范围需同步调整。

## 九、其他版本

原版、方案A、互补版、m20、m25、全信号参考版均保持现状，只改 m30 正式版。
