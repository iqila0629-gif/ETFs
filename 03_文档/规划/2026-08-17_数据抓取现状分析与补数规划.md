## 一、结论摘要（给上司 30 秒版）

1. **总账 453 支**：约 8 成（362 支）已找到数据来源，其中 **133 支已确认可用**（56 支已落盘价格文件）；**71 支正在用 EODHD API 自动补齐**；20 支债券/结构性产品免费源无解。
2. **已落盘价格文件 74 支** = Yahoo 56 支（长历史，多数 2022 起，截至 2026-08-13）+ EODHD 18 支（约 1 年，2025-08-18 至 2026-08-13/14）。
3. **最大风险不是"拿不到"，而是"拿错"**：名称搜索命中后约 42%（127/304）存在币种/份额问题，必须以 ISIN 交叉核验后才可进建模。
4. **瓶颈是免费额度与人工核验量**：EODHD 8 key 每天 160 次调用，71 支约需 4-6 个工作日拉完；另有 225 支（待核 150 + 误配 21 + 重试找回 54）需人工复核份额/币种。
5. **明确无解约 20-27 支**（债券/结构性 20 支 + 小众基金预计 5-7 支），建议直接标记"无数据"并出报告，不死磕。

## 四、匹配与质量核查（"是否匹配"）

### 4.1 名称规范化（已基本完成，需固化）

- 原始 457 条 → 规范化去重 453 条唯一名称；曾因**连续空格差异**造成清单与总账对账偏差（如 "BLACKROCK ... HIGH INCOME FUND  D6 USD" 双空格），现已按"压缩空格 + 去序号"统一。
- 需固化一张**名称规范化表**（原名 → 规范名），并处理文件名非法字符：**"FTGF GBL W/A ..." 落盘时自动写成 "W_A"**（Windows 文件名不能含 `/`），合并面板时要做回映射。

### 4.2 Yahoo 符号审计（304 个候选，`eip_audit_result.csv`）

| 结论 | 数量 | 说明 |
|---|---:|---|
| 确认 | 133 | 名称家族 + 币种 + 份额一致，可建模 |
| 存疑-币种不符 | 106 | 找到的是 EUR/GBP/SGD/HKD 份额，清单要 USD（或 HKD 对 USD 等） |
| 存疑 | 41 | 名称相似但无法确认 |
| 疑似误配 | 21 | 明显配错，需换 |
| 无名称信息 | 3 | Yahoo 无名称元数据 |
| 合计 | 304 | 仅 44% 可直接用 |

### 4.3 EODHD 份额/币种问题（建模前必须处理）

1. **FRANKLIN TEMPLETON GLOBAL TOTAL RETURN 两只都拉错份额**：A MDIS 与 FUN A ACC 均落盘为基础份额 `LU0260871040`。正确份额应为 **MDIS → LU0170475585、ACC → LU0170475312**，需改 MAP 重拉。
2. **ALLIANCEBERNSTEIN AMERICAN INCOME USD**：清单名未写 ACC/INC，"INCOME" 是策略名；当前解析到 S USD Acc（LU0231611335）是**假设**，需与上司确认；FT 候选 IT0005630238 是 Growth≠Income，**疑似错误，勿用**。
3. **CTMGMT LUX AMERICAN AU USD ACC**：拉到的是 AE 份额（LU0757425094），需确认是否接受 AE 近似或改拉 AU。

### 4.4 结论口径

- **宁可少、不可错**：无法交叉验证的一律进"待人工核"，不进建模集（延续 v2 规划）。

| SKIP-结构件 | 18 | 跳过不拉 |
| 合计 | 71 | |

预计 4-6 个工作日（160 次/天）拉完；NOT_FOUND 中 **Franklin Global Focus×2、Celerity、FincRest 大概率真无解**，经第二轮确认后标记。

### 5.2 EODHD 无解后的兜底

1. **investing.com 人工下载 39 支**（32 有 + 7 需核），按 `2026-08-14_investing搜索词清单_手动下载.md` 逐支核对份额/币种后下载。
2. **FT Markets / fundinfo / wallstreet-online** 补漏（FT 约 1 个月免费可做身份验证；fundinfo 需注册；wallstreet 可导出历史）。
3. 人工文件放 `01_数据/人工下载/`，跑 `import_manual_downloads.py` 导入并更新总账。

### 5.3 其余缺失的处理

- **77 支"已确认未落盘"**：符号已确认（Yahoo），直接批量下载补齐（含 76 支基金 + 部分股票/债券类，股票/债券类按"非基金"单独标注）。
- **150 待核 + 21 误配**：用 FT 1 个月数据做 **ISIN/币种/份额身份核验**，修正映射后重拉；优先核"可建模"所需，其余降级待补。
- **54 重试找回**：复核名称重叠与币种后并入确认/待核。
- **4 支股票**：基金建模时剔除，单独列出。
- **20 支债券/结构性/ETP**：免费源无解，**维持"不下载"标记**（如需纳入，须购买数据源或用户提供）。
- **无完整 2025 数据的基金**：已发现 ≥4 支，全量下载完成后扫描一遍，**单独出一张表**，不与其他基金混放（用户已确认口径）。

## 八、验收标准

1. 453 支全部有明确状态：有数据（可建模/待核）/ 无数据（带原因）。
2. 每支有数据基金可追溯：来源、ISIN、符号、核验结论。
3. 面板日期与 19 支 ETF 对齐，无未来函数，口径一致（Adj Close/NAV）。
4. 无 2025 数据的基金单独成表；债券/结构性无解项有清单与原因。
5. 份额/币种存疑项全部列出，未核验的不进建模集。
