# 交接文档：新基金类型从 0 开始复用索引

日期：2026-08-14

目标：下一窗口要做“ETF 对应新的基金类型”。本文档提供从原始数据到最终交付的可复用资料索引，方法不依赖具体 ETF/基金名，可扩展到其他资产类型。

## 一、抽象流程

现有 v4 流程可抽象为 6 个阶段：

1. 原始数据采集：目标资产、参考资产、外部环境。
2. 清洗与面板：异常处理、单位统一、衍生列。
3. 条件穷举：单/双/三/复合/外部/自身 + horizon 网格。
4. 合规筛查：门槛、命中率、平均回报、交易数、密度、冲突。
5. 最佳策略提取：每目标资产选策略、合并、备份。
6. 交付：Excel 公式版、说明、报告、质检。

术语替换表：

| 旧叫法 | 通用叫法 |
|---|---|
| ProFunds 基金 | 目标资产 Target |
| ETF | 参考资产 Ref |
| VIX/TNX | 外部环境 External |
| 每基金最佳策略 | 每目标资产最佳策略 |

## 二、资料索引（按阶段）

### 1. 数据采集

- 参考脚本：
  - `02_脚本/adj_close_v4/update_etf19_yahoo.py`：Yahoo v8 chart 抓取 OHLCV + Adj Close。
  - `02_脚本/adj_close_v4/update_vix_tnx_yahoo.py`：外部指数 OHLC，幂等合并 `external_daily.csv`。
  - `03_文档/项目要求/数据爬取方法详细指导.md`、`免费数据源调研报告.md`。
- 数据位置：
  - `01_数据/event_study_inputs/`：建模输入。
  - `04_结果/最新成果/数据/数据_原始/`：交付原始副本。
  - `最新结果/数据/数据_原始/`：打包交付副本。
- 要点：统一日期格式；Adj Close 与 Close 的区别；指数类 Volume 常为 0。

### 2. 数据清洗与面板

- `02_脚本/adj_close_v4/clean_profunds_outliers.py`：单日尖峰回补、复权断层前值调整；日志 `01_数据/processed_returns/profunds_cleaning_log.csv`。
- `02_脚本/adj_close_v4/build_v4_panel.py`：读原始面板 -> 截断异常 -> 合并参考/外部 -> 输出 `v4_etf19_panel.csv`、`v4_etf20_panel.csv`、`v4_external_panel.csv`。
- `02_脚本/adj_close_v4/config.py`：所有路径、资产清单、单位、阈值集中管理。新项目第一件事就是替换这里的清单和阈值。
- 泛化：清洗规则只依赖价格序列；面板构建只需 `Date` + 各资产列，不依赖 ETF/基金名。

### 3. 条件穷举

- `scan_v4_thresholds.py`：门槛敏感性扫描（全历史/冻结期），输出基线。
- `scan_v4_triple.py`：三信号穷举，输出 `v4_triple_pass_v2.csv`。
- `scan_v4_conditions.py`：外部/自身/复合条件 + 1/2/3/5/10 日窗口，输出条件扩展通过表。
- `recompute_76_pool.py`、`build_v4_final_pool.py`：重算单/双条件池并合并正式信号池。
- 中间产出：`04_结果/v4_中间结果/*.csv`。
- 泛化：条件生成器按“参考资产列 + 操作符 + 阈值 + horizon”参数化，不写死资产名。

### 4. 合规筛查

- 门槛规则见 `config.py` 与 `select_v4_strategies.py`：
  - 全历史交易数 >= 120，冻结期 >= 30。
  - 命中率 >= 55%。
  - 平均回报 >= 0.2% / 0.3%（不同版本）。
  - 密度档位 200/40 -> 160/35 -> 120/30。
- `select_v4_strategies.py`：时间互补贪心 + 边际 Average 下限 + 冲突规则。
- 辅助分析：`analyze_v4_gap.py`、`analyze_v4_conflict_loss.py`、`analyze_v4_average_dilution.py`、`merge_signals_v4.py`、`optimize_v4_all_signal.py`。
- 相关报告：`03_文档/评估/`、`04_结果/v4_中间结果/*.md`。

### 5. 最佳策略提取

- `select_v4_strategies.py` 输出：
  - `v4_strategy_selection_m30_v2.csv`
  - `v4_strategy_mapping_m30_v2.csv`
- 口径：每目标资产 1-3 条（部分放宽 <=5），按 |Average| 排序，冲突按规则取舍。
- 备份惯例：`04_结果/备份_m30_v2_旧版式/`、`备份_m30_v2_新版式_未清洗/` 等，每次重生成前先复制原版。

### 6. Excel 转换与公式书写

- `build_v4_m30_full_newformat.py`：主生成脚本（统计头、阈值、数据、策略公式、基金基础数据 Sheet）。
- `build_v4_m30_newformat_sample.py`：两基金示例 + 条件解析/标签/阈值 helper。
- `build_v4_external_sample.py`：外部数据新版式示例。
- `patch_v4_m30_note_sheet.py`：说明 Sheet 补丁。
- `build_v4_delivery.py`：旧公司格式彩色交付，可作参考。
- 公式规范：
  - 回报 = `(今日 Adj Close / 前日 - 1) * 100`，用 COUNT 守卫空值。
  - horizon>1：未来 N 日平均，带 IFERROR。
  - 策略目标 `ABS <= 50` 守卫；self_3/5 用降序行 `r+1/r+2`（过去日），不能写成未来日。
  - 统计头单位按列区分：百分比 / bp / 普通数字 / Volume 整数。
  - 除法类公式（如 VIX_TNX_Ratio）必须 IFERROR。
- 示例：`04_结果/示例审批/`。

## 三、新项目启动 checklist

1. 新建/修改 `config.py`：资产清单、路径、单位、阈值。
2. 接入原始数据 -> 统一 `Date` + 数值列。
3. 清洗 -> 构建面板（含外部衍生列）。
4. 单/双/三/复合/外部/自身条件穷举。
5. 合规筛查 + 门槛敏感性。
6. 最佳策略提取 + 原版备份。
7. Excel 公式版 + 说明 Sheet + 示例审批。
8. md 报告 + 自查清单。
9. 同步 `最新结果/` 交付包。

## 四、通用化要点

- 条件系统只依赖列名 + 操作符 + 阈值 + horizon。
- 清洗只依赖价格序列。
- 统计口径（全历史/冻结期、Average、命中率、交易数）全部参数化。
- Excel 生成只依赖列映射：目标价格/回报、参考资产、外部、策略。
- 新资产类型只需改 config 与数据接入，扫描、选择、交付代码可复用。

## 五、已知坑（复用前必读）

- 未来函数：self_3/5 方向、horizon 目标期，降序表必须检查行方向。
- `#DIV/0!` / `#VALUE!`：除法公式、空目标、历史边界。
- 统计头单位：价格/Volume/相关系数不能统一显示百分比。
- 日期窗口一致性：最新交易日是否两边同步。
- 截断 vs 清洗口径差异：交付说明要写清楚。
- 大文件不入 git：换机器或克隆后需要重新生成。
