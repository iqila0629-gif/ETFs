  - 全历史：`|Average| >= 0.2%`、交易数 `>= 50`、命中率 `> 55%`

### Phase 2：提高两时期交易数门槛

建议先跑门槛敏感性，不直接拍板数值：

```text
全历史交易数：50 / 80 / 100 / 120
冻结期交易数：10 / 15 / 20 / 30
```

对每一组门槛，在“原始 19 支 + 当前双条件信号池”上重新统计：

- 正式信号数
- 覆盖基金数
- 未覆盖基金清单
- 每基金最佳策略的全历史/冻结期 Average、命中率、交易数中位数

推荐默认值：全历史 `>= 100`、冻结期 `>= 20`；若覆盖损失过大，再看敏感性表折中。

命中率与 Average 门槛保持不变（全历史 `> 55%`、冻结期 `>= 55%`、`|Average| >= 0.2%`），除非敏感性结果显示需要单独确认。

### Phase 3：三信号穷举扫描 + 其他补缺口方法

#### 3.1 三信号穷举（新增）

在原始 19 支 ETF 上扩展“三支 ETF 同时满足方向”的条件：

```text
ETF 组合：C(19,3) = 969 组
方向模式：8 种（全涨、全跌、2涨1跌、1涨2跌等，可先全量再筛选）
预测窗口：1 / 2 / 3 日
基金：129 支
约 969 x 8 x 3 x 129 ≈ 300 万个基金-条件组合
```

实现要点：

- 复用 v3 的 `evaluate_signal` 逻辑（expanding walk-forward，禁止未来信息）。
- 用 numpy 向量化，先按事件数预筛（`full_trades >= 门槛`、`frozen_trades >= 门槛`），只输出有潜力的行，不输出全部 300 万行。
- 严格版仍要求未来 N 天全部有数据；与双条件口径保持一致。
- 若“三信号”不是指三支 ETF，而是指“ETF + 外部 + 自身”任意三类信号组合，需先确认条件空间定义。

#### 3.2 其他补缺口方法（按优先级）

1. 外部信号：VIX 变化/水平、TNX 变化、派生特征（已有部分，继续用于 19 ETF 场景）。
2. 基金自身信号：连跌 3 日反转、大涨大跌反转。
3. 高相关 ETF 映射：给每支未覆盖基金找最相关原始 ETF，构造专属条件。
4. 多日窗口：2/3/5 日日均回报，注意与 1 日口径分开标注。
5. 低波动基金：若 0.2% 门槛在物理上不可达，输出“建议接受缺口”或“需新数据源”的证据表。

产出：

- `04_结果/v4_中间结果/v4_triple_scan_stats.csv`
- `04_结果/v4_中间结果/v4_gap_fill_validated.csv`
- `04_结果/v4_中间结果/v4_缺口基金诊断.csv`

### Phase 4：每基金多策略选择与冲突规则

目标：每支基金不再只保留 1 条，而是保留不超过 3 条（部分可放宽到 5 条），且整体质量不显著低于该基金的全信号组合。

步骤：

1. 从 v4 通过信号池中，按基金提取候选策略。
2. 对每个基金选策略集合，候选方法：
   - 按 `|全历史 Average|` 排序取 Top-N；
   - 按“互补性”选（不同 ETF 方向、不同窗口、不同触发类型）；
   - 按“交易数补齐”选（先保证覆盖和交易数）。
3. 质量约束建议先量化，例如：
   - 策略集合合并后的 `|Average| >= 全信号组合的 90%`；
   - 命中率不低于全信号组合 3 个百分点；
   - 交易数不低于全信号组合的 80% 或最低门槛；
   - 具体阈值待用户确认。
4. 冲突规则候选并做对比：
   - R4：同日取 `|全历史 Average|` 最大；
   - 多数投票：同日多个策略方向一致才出手，冲突日跳过；
   - 优先级排序：按综合得分（avg/hit/trades）排序取最高；
   - 加权融合：按全历史 Average 加权输出方向。
5. 评估维度：基金级 Average、命中率、交易数、冲突日占比、与全信号组合的差距。

产出：

- `04_结果/v4_中间结果/v4_strategy_selection_report.md`
- `04_结果/v4_中间结果/v4_strategy_mapping.csv`
- `04_结果/v4_中间结果/v4_conflict_rule_comparison.csv`

### Phase 5：彩色交付格式生成与校验

按 Phase 0 审批通过的版式生成正式成果：

- 每支基金最多 3 条策略（放宽后最多 5 条），策略名行填色；
- 数据区日期格子按“当日生效策略”填色，格子内填实际回报（%），未触发留空；
- 保留公司 13 行统计头，公式区间按策略图例行下移；
- 冻结期和全历史各一份；
- 每基金策略映射、信号逐日明细、覆盖情况同步更新。

校验项：

- Excel 无公式错误；
- 颜色与策略映射一一对应；
- 日期着色与逐日明细交叉核对一致；
- 每基金最佳/策略集合的统计与明细一致；
- 覆盖表与信号池一致。

## 三、关键决策点清单

执行前需要确认：

1. 两时期交易数新门槛（建议先看敏感性表）。
2. “三信号”定义：三支 ETF，还是 ETF+外部+自身 的组合。
3. 每基金策略数量：默认 3，哪些基金可放宽到 5。
4. 质量约束如何量化：“不显著低于全信号组合”的具体阈值。
5. 冲突规则：R4 / 多数投票 / 优先级 / 加权。
6. 颜色方案：策略全局统一色或基金内部色。
7. 是否保留公司 13 行统计头。
8. 扩展 ETF 备份是否进入 Git 仓库。

## 四、风险与注意事项

- 提高门槛后覆盖可能明显下降，三信号扫描不一定能完全补回，低波动基金存在物理上限。
- 19 支 ETF 严格口径下覆盖约 100 支（旧门槛），新门槛后可能更少；需要明确“覆盖优先”还是“门槛优先”。
- 多策略会让 Excel 列数/行数显著增加（119 基金 x 3-5 策略），注意文件大小和公式性能。
- 旧脚本大量硬编码 `C:\Users\vanessacen\Desktop\基金预测`，v4 必须先集中配置路径。
- 冻结期只有约 1.5 年，`>= 20` 或 `>= 30` 会淘汰大量信号，需在报告中标注样本风险。
