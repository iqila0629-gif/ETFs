# 数据获取 v2 规划：多数据库补齐缺失基金数据

> 日期：2026-08-14
> 目标：补齐 `新数据/` 清单中**尚未获得**的基金数据（149 无数据 + 21 误配需换正确 + 150 待核尽量升级），最终给出一份“可建模 / 待人工 / 无数据”的可靠覆盖表
> 背景：v1（Yahoo + FT 按名称）拿到 304 个“有数据”，但核验后仅约 133 个可靠；单纯按名称匹配不可靠，必须以 **ISIN 为中心 + 多数据库交叉**。

## 一、现状盘点

| 状态 | 数量 | 说明 |
|---|---:|---|
| 有数据（总） | 304 | 其中可用 133 / 待核 150 / 误配 21 |
| 无数据 | 149 | 基金 ~109、结构性 ~22、债券/票据 ~14、股票/ADR ~3-9 |

缺失基金分布：约 50 个基金公司，每家 1-6 支（BlackRock 7、Causeway/BNP 6、Franklin 5、JPMorgan 5 等），**逐家对接官网收益低，优先通用基金库**。

## 二、数据源能力矩阵（已探明）

| 数据源 | 按名称搜 | 按 ISIN | 历史深度 | 可靠性 | 备注 |
|---|---|---:|---:|---|---|
| Yahoo Finance | ✓ | 部分（结果有时错配） | 长（多数 2021 起） | 中 | 干净核心词可找回一批；按 ISIN 返回的符号需用 FT 名称核对 |
| FT Markets | ✓ | ✓（精确 ISIN） | 仅约 1 个月（免费） | 高（身份） | **ISIN 的权威来源**，历史不足以建模，但可做币种/份额验证 |
| fundinfo.com（FE） | 页面 JS 渲染 | 待逆向 apiKey | 专业库 | 高 | 需逆向其搜索/净值接口（下一步） |

| 债券/结构性产品 | — | — | — | — | 免费源基本无解，标记“无数据” |

## 三、核心策略

1. **身份先行**：先用 FT（+后续 fundinfo）把所有能找到的名称 → ISIN 映射做全，ISIN 是最终核对/取数锚点。
2. **数据多源**：同一 ISIN 在 Yahoo / 基金公司官网 / FT（1 个月，仅验证）等多处核对；Yahoo 符号必须满足“名称家族 + 币种 + 份额”一致才采信。
3. **按可得性分层**：先抓容易的（股票/ADR、主流大厂基金），再攻难啃的（小众基金），最后明确标记无解项（债券、结构性产品）。
4. **不采信单一来源**：宁可少，不可错——无法交叉验证的一律进“待人工核”，不进建模集。

## 四、分阶段执行计划

### Phase A：缺失集全量重试（先执行，收益最高）
- 对 149 无数据 + 21 误配名称，用“最干净核心词”重试 Yahoo（如 Brown Advisory、Causeway、Arbrook、Pictet、Bank of America、Evolution）。
- 股票/ADR：Bank of America→BAC、Evolution→EVO.ST（SEK 代理）、Unilever→UL 等。
- 命中后 chart 验证 + 名称/币种核对，进入“有数据”但按可靠度分级。
- 产出：`eip_retry_results.csv` + 更新覆盖表。
- 期望：至少再找回 30-60 个。

### Phase B：ISIN 补齐
- 对仍无 ISIN 的名称，用 FT 查询变体重试（换关键词/去掉公司名只留主题词/用缩写）。
- 逆向 fundinfo.com 搜索接口（页面 JS 里的 apiKey + data-ajax 端点），按名称/ISIN 查。
- 尝试 Morningstar 基金搜索页（需处理 JS/cookie）。
- 产出：ISIN 清单从 138 扩大到尽可能多（目标 200+）。

### Phase C：多数据库历史抓取（按 ISIN）
- Yahoo：对每个 ISIN，用 FT 基金名核对 Yahoo 返回符号（名称家族+币种+份额一致才采信）；不一致的标记“Yahoo无对应”。
- 基金公司官网：对 BlackRock（BGF，7 支）、Allianz、Fidelity、JPMorgan 等最大几家，对接官方基金页/接口拿 NAV（按 ISIN）。
- 浏览器自动化（如 wallstreet-online）：对仍缺的小众基金，用可脚本化浏览器抓历史（作为最后手段，先评估是否值得）。
- FT 1 个月数据：仅用于核验“该 ISIN 确实存在、币种正确”。
- 产出：每个名称 0-2 个数据源及其核对结论。

### Phase D：定稿覆盖表
- 合并 Phase A-C，输出最终分级：
  - **可建模**：ISIN（或强名称+币种）一致且有数据
  - **待人工核**：数据存在但身份存疑（列明疑点）
  - **无数据**：债券/结构性产品/两库均无（列原因）
- 产出：`eip_final_v2.csv`、`eip_model_ready.csv`、`eip_no_data_final.csv`。

### Phase E：进入建模
- 与既有规划衔接：清洗 → 面板（仅原始 19 ETF）→ 扫描 → 门槛 → 选策略 → 交付。
- 无 2025 数据/无数据基金单独成表，不混入。

## 五、验收标准

1. 覆盖表逐条有出处：来源、ISIN、符号、核对结论。
2. 可建模集内每条都能对应到精确身份（ISIN 优先）。
3. 债券/结构性产品明确标“无数据”，不再尝试。
4. 无人工干预可复现（脚本化、缓存化）。

## 六、风险与预期

- Yahoo 对部分 ISIN 无正确符号 → 这些基金只能等官网/浏览器自动化，或标“待补”。
- 德系门户、investing、MarketScreener 被挡 → 浏览器自动化成功率不确定，先小样本验证再投入。
- 基金公司官网接口形式各异 → 只对最大几家做，其余用通用库兜底。
- 债券/结构性产品（约 36 个）确定无解 → 直接标记，不再耗时。
- 预期最终：可建模 180-250、待核 30-60、无数据 60-90（含 36 个债券/结构 + 其余基金）。

## v3 更新（2026-08-16）：改用“批量目录 + 本地 JOIN”，不再逐基金搜索

> 背景：逐基金浏览器搜索（fundinfo 自动补全）可行但太慢（每支 15-25 秒，72 支要 30+ 分钟且浏览器会话易卡）。用户建议改为**先抓网站全量基金目录，本地和 453 个清单做 JOIN**。

### 已验证的事实（实测）

1. **ariva.de（www.ariva.de）可纯 HTTP 抓取，且是批量目录入口**：
   - 基金按 ISIN 直接开页：`https://www.ariva.de/<ISIN>`（如 `LU0107464264` → abrdn Future Global Equity A Acc USD，含 WKN、同基金其他份额链接）。
   - **Fonds-Finder 按基金公司批量返回份额列表**：
     `https://www.ariva.de/fonds/finder?fltr_m_holdingCompany00keyword=<基金公司名>`
     - abrdn Investments Luxembourg S.A. → abrdn 全部份额；BlackRock (Luxembourg) S.A. → BGF 份额（25 条/页），**ISIN 出现在结果页**（URL slug 部分带 ISIN + 页内表格）。
   - 基金页有 `historische_kurse`（历史数据页），表单参数 `boerse_id / month / currency / clean_bezug` 可控制区间与调整口径（参数细节待细化）。
2. **fundinfo.com（已登录）可拿精确份额 ISIN**：名称自动补全 → 基金落地页列出所有份额（份额名+币种+Acc/Dist+ISIN）。例：Pictet Megatrend I USD Acc = LU2850666467（比 FT/Yahoo 更准）。
3. **FT Markets**：仅约 1 个月免费历史；档案 PDF 需订阅。
4. **wallstreet-online**：账号激活失败，需重新点邮箱激活链接。
5. **onvista/investing/MarketScreener/finanzen.net**：403/429 被挡。

### 新方案（取代逐基金搜索）

```
Phase A1 建 ariva 基金目录（批量，纯 HTTP）
  按 ~50 个基金公司名（从已有 ISIN 的基金页反推 + 常见公司名）逐个查 finder
  -> 得到 (基金名/份额, ISIN, 币种, WKN) 大表
Phase A2 本地 JOIN
  453 个清单名 与 ariva 目录匹配（名称+份额+币种）-> 缺失基金补 ISIN
Phase A3 补漏
  仍未命中的 -> fundinfo（登录会话）按公司/名称批量查（组级浏览，不是逐基金）
Phase B 历史数据（按 ISIN）
  ariva historische_kurse（表单参数）批量拉日频 NAV -> 建面板
  或 FT 1 个月做身份/币种验证
Phase C 定稿
  有数据/待核/无数据 分级，无解（债券/结构性）标记
```

### 预期

- 缺失 72 支基金中，主流卢森堡/爱尔兰 UCITS（Arbrook、Pictet、BlackRock、Franklin、JPMorgan、Invesco、Montlake、Schroder 等）大概率能在 ariva/fundinfo 找到正确 ISIN 与历史；少数小众基金和债券/结构性维持无解。
- 全程脚本化、可缓存、可复现；不再依赖易卡的浏览器逐基金会话。
