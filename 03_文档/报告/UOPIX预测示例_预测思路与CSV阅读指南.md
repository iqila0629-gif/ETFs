# UOPIX 预测示例：预测思路与 CSV 阅读指南

> 日期：2026-07-31
> 模型：ETF 事件驱动条件统计预测模型
> 示例基金：UOPIX（2x Nasdaq-100，杠杆多头）

---

## 一、为什么拿 UOPIX 举例

UOPIX 是本项目里最稳定的达标基金之一：

- 它有 10 个通过 walk-forward 稳定性验证的条件
- 冻结样本外（2025-2026）继续达标
- 日频合并口径 Average = +0.2585%，超过 0.2% 门槛
- 方向准确率 56.33%

---

## 二、预测思路（一句话）

**今天某支 ETF 出现了特定涨跌 → 查历史数据里同样情况发生过的日子 → 统计明天 UOPIX 是涨是跌、涨跌平均多少 → 只有历史胜率和平均回报都够高时才出手。**

---

## 三、用一个条件讲完整逻辑：`FXY_big_up`

### 3.1 条件是什么

`FXY_big_up` = 日元 ETF（FXY）当日涨幅达到 1% 或以上。

### 3.2 历史统计（全量样本）

1997-2026 年中，FXY 单日涨 ≥1% 共出现 246 次，统计次日 UOPIX：

| 指标 | 数值 |
|------|------|
| 事件天数 N | 246 |
| 次日上涨概率 P_up | 58.94% |
| 次日下跌概率 P_down | 39.43% |
| 次日上涨时平均回报 Avg_up | +3.1694% |
| 次日下跌时平均回报 Avg_down | -2.8180% |
| 条件期望回报 | +0.7570% |

### 3.3 决策规则

满足三个条件才预测"涨"：

1. 历史上同类事件至少出现过 100 次
2. 次日上涨概率 ≥ 55%（这里是 58.94%）
3. 上涨时平均回报 ≥ 0.2%（这里是 3.17%）

→ 预测 UOPIX 明日上涨，出手。

### 3.4 一个真实触发日

以 `04/30/2026` 为例：

| 项目 | 数值 |
|------|------|
| 04/30/2026 当天 | FXY 上涨 2.39%（满足 ≥1%） |
| 历史规则判断 | 预测涨（历史 Avg_up ≈ 3.18%） |
| 05/01/2026 实际 | UOPIX 上涨 +1.8737% |
| 这次预测 | 正确 |

再举例 `03/19/2026`：

| 项目 | 数值 |
|------|------|
| 03/19/2026 当天 | FXY 上涨 1.39%（满足条件） |
| 历史规则判断 | 预测涨（历史 Avg_up ≈ 3.18%） |
| 03/20/2026 实际 | UOPIX 下跌 -3.7547% |
| 这次预测 | 错误 |

模型不是每次都对，靠的是"历史胜率 58.94% + 平均回报 0.76%"累计达到 0.2% 门槛。

## 四、怎么读预测 CSV（稀疏版）

文件：`analysis_results/event_study/predictions/UOPIX__FXY_big_up.csv`

### 4.1 前 13 行（固定统计头）

```text
（第1行空白）
Hit Ratio,0.618321     ← 击中率：81/(81+50)
Up Count,81            ← 131 个触发日中，次日上涨 81 次
Down Count,50          ← 次日下跌 50 次
Average,0.755959       ← 131 个触发日次日实际回报的平均值（验收标准看这里）
Max,23.954061          ← 最大次日回报
Min,-12.172805         ← 最小次日回报
Count,131              ← 触发日总数
Std,4.107144           ← 标准差
Sum,99.030596          ← 次日回报总和
（第11-12行空白）
Date,Daily Return (%)  ← 第13行：列名
```

### 4.2 数据行怎么读

```text
Date,Daily Return (%)
04/30/2026,1.873699
03/19/2026,-3.754682
02/10/2026,0.560702
...
```

每一行代表一个**触发日**：

- `Date` = 条件发生的当天（ETF 涨跌当天）
- `Daily Return (%)` = **次日 UOPIX 的实际回报**，不是预测值

所以 `04/30/2026,1.873699` 的意思是：04/30 FXY 大涨触发，第二天（05/01）UOPIX 实际涨了 1.8737%。

**没有出现的日期 = 没有触发 = 不操作**。这个文件是稀疏日频，只保留出手的日子。

### 4.3 预测值在哪里看

预测方向和预测值在 `analysis_results/event_study/prediction_log.csv`：

```text
ticker condition  date       decision  predicted_return  actual_return
UOPIX  FXY_big_up 04/30/2026 predict_up 3.178389         1.873699
UOPIX  FXY_big_up 03/19/2026 predict_up 3.178389         -3.754682
```

## 五、怎么读完整日频表

文件：`analysis_results/event_study/daily_predictions_all_funds.csv`

这张表**每个交易日都有一行**（共 7,219 行），一列一支基金：

```text
Date,UOPIX,ULPIX,...
07/27/2026,,,
04/30/2026,1.873699,0.555263,
...
10/30/1997,,,
```

读法：

- `Date` = 当天日期
- `UOPIX` 列有数字 = 当天触发了 UOPIX 的某个稳定条件，数字是次日实际回报
- `UOPIX` 列空白 = 当天没有触发，不操作

同一基金多个条件在同一天都触发时，只记一次，避免重复计数。

## 七、常见问题

**Q：为什么 CSV 不是每天都有值？**
A：模型只在条件触发且历史胜率达标时出手。不满足就空着/不出现，这是"主动不操作"。

**Q：CSV 里的数字是预测回报吗？**
A：不是。13 行标准格式里的数字是**次日实际回报**，用于统计 Average 验收。预测方向/预测值在 `prediction_log.csv`。

**Q：想看每天的情况？**
A：看 `daily_predictions_all_funds.csv`，每个交易日都有一行。

**Q：条件之间会重复触发吗？**
A：会。完整日频表已按基金按日期去重；稀疏 CSV 是每个条件单独一张表，可能同日多条件触发。
