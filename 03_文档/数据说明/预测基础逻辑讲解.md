# Profund 基金回报率预测：基础逻辑讲解

## 一、一句话说清楚我们在做什么

我们有 129 支 Profund 基金的过去 28 年每日数据。我们也会拿到 19 支 ETF 的过去每日数据。
**我们要做的事情是：** 利用 ETF 今天的涨跌，来预测对应的 Profund 基金明天或者后天的涨跌。

打个比方：
- ETF 就像一个先行指标——它是我们判断方向的温度计
- Profund 基金就是我们最终要下注的天气
- 模型要做的事就是：看温度计上的数字，推测明天的天气

## 二、基本概念：日回报率

每个工作日，每支基金的净值（NAV）都会发生变化。

**日回报率 = （今天的 NAV - 昨天的 NAV）/ 昨天的 NAV x 100%**

例如：
- UltraBull（ULPIX）昨天 NAV = 100，今天 NAV = 102
- 日回报率 = (102 - 100) / 100 x 100% = **+2.0%**

如果今天涨了就叫正回报，跌了就叫负回报。零就是没变。

## 三、Profund 基金的特殊性：杠杆

Profund 基金不是普通基金——它们是用衍生品构建的杠杆基金。

| 类型 | 例子 | 什么意思 |
|------|------|---------|
| 1x（经典）| Bull（BLPIX）| 指数涨 1%，它也涨约 1% |
| 2x（Ultra）| UltraBull（ULPIX）| 指数涨 1%，它涨约 2% |
| -1x（逆）| Bear（BRPIX）| 指数涨 1%，它跌约 1% |
| -2x（超逆）| UltraBear（URPIX）| 指数涨 1%，它跌约 2% |

杠杆的后果：Profund 基金的波动天然比普通基金大 2 倍甚至更多。这反而让它们的可预测性更高——因为信号的幅度被放大了。

## 四、为什么 ETF 能帮我们预测：领先滞后关系

关键问题：ETF 收盘价和 Profund 净值几乎同时出来，怎么用今天的数据预测明天的结果？

答案藏在跨时间的统计关系里。

### 4.1 同步关系（不能用来预测）

SPY 今天涨 1%，UltrBull（ULPIX）今天涨约 2%。这是同一天的联动，我们知道了也没有用，因为我们要在今天收盘前就知道结果。

### 4.2 跨日的关系（可以用来预测）

我们要找的是这种关系：**T 日的 SPY 上涨，导致 T+1 日的 ULPIX 有较大概率上涨**。

某些资产类别的变动会传导到其他资产：

| 传导链条 | 逻辑 |
|----------|------|
| TLT（长债）下跌 -> 股市上涨 | 利率下降，资金从债市流入股市 |
| UUP（美元）上涨 -> EEM（新兴市场）下跌 | 美元走强，新兴市场资金外流 |
| GLD（黄金）上涨 -> 股市下跌 | 避险情绪升温，资金从股市转入黄金 |
| HYG（高收益债）下跌 -> 股市下跌 | 信用利差扩大，风险偏好下降 |

这些传导不是瞬间完成的——市场需要时间来消化和反映新的信息。这个时间差就是我们做预测的空间。

## 五、三种预测方法（从简单到复杂）

### 方法一：看历史命中率（Hit Ratio）

最简单的方法：回顾历史，统计当 SPY 今天上涨时，ULPIX 明天上涨的概率有多大。

具体做法：
1. 把历史数据按日期排好
2. 找出所有 SPY 上涨的日子
3. 看那些日子之后一天，ULPIX 是涨还是跌
4. 算比例：ULPIX 涨的次数 /（涨+跌的次数）= 命中率

命中率 > 55% 就说明有预测价值（抛硬币才 50%）。
命中率 > 60% 就很有用了。

### 方法二：相关性分析 + 最佳领先天数

这个方法回答一个更精确的问题：ETF 的变化要提前几天，才能最好地预测 Profund 的变化？

具体做法：
1. 把 SPY 今天的回报率，和 ULPIX 明天、后天、大后天的回报率分别做相关性分析
2. 看看哪一天（T+1, T+2, T+3...）的相关性最高
3. 那个天数就是最佳领先天数

相关性系数在 -1 到 +1 之间：
| 数值 | 含义 |
|------|------|
| +0.5 以上 | 强正相关：ETF 涨 -> Profund 大概率涨 |
| +0.2 到 +0.5 | 弱正相关：有一定参考价值 |
| -0.2 到 +0.2 | 几乎无关：没什么预测价值 |
| -0.5 到 -0.2 | 弱负相关：有点反着走 |
| -0.5 以下 | 强负相关：ETF 涨 -> Profund 大概率跌 |

### 方法三：阈值信号系统（最实用）

这是目前来看最适合我们业务场景的方法。

思路：我们不追求精确预测明天涨多少，而是寻找强烈信号——当 ETF 的变动幅度超过某个阈值时，对应 Profund 基金后续有很高概率出现 >=+0.2% 或 <= -0.2% 的回报。

具体做法：
1. 从历史数据中，统计当 SPY 涨幅 >1% 时，第二天 ULPIX 平均涨多少
2. 如果统计结果显示：SPY 涨 >1% 的次日，ULPIX 有 65% 的概率涨 >0.2%
3. 那么这个信号就是有效的——下次 SPY 涨 >1% 时，我们就知道应该配置 ULPIX

## 六、用实例走一遍完整流程

虽然我们还没有 ETF 数据，但可以用两支 Profund 基金来模拟预测的思路。

### 测试对象：
- 预测目标：UOPIX（UltraNasdaq-100，2x 杠杆）明天的涨跌
- 特征指标：ULPIX（UltraBull，2x S&P 500）今天的涨跌

虽然两支基金跟踪不同指数（Nasdaq vs S&P 500），但大盘和科技股的相关性很高，所以 ULPIX 对 UOPIX 有一定的预测力。

用 ULPIX 今天的涨跌，来看 UOPIX 明天的涨跌。

ULPIX 自身统计：
- 数据量：7207 个交易日
- 平均日回报率：0.1613%
- 上涨天数：3831，下跌天数：3333
- Hit Ratio（上涨概率）：53.5%

### 预测结果演示：

1. **ULPIX 今天上涨 -> UOPIX 明天上涨**
   命中率 = 54.9%（共 3831 次信号）
   解释：当 S&P 500 今天上涨时，Nasdaq-100 明天有 55% 的概率也上涨。

2. **ULPIX 今天大涨 >2% -> UOPIX 明天上涨**
   命中率 = 53.0%（共 1044 次强烈信号）
   解释：当大盘今天大涨 >2% 时，科技股明天上涨的概率是 53%。

3. **ULPIX 今天大跌 >2% -> UOPIX 明天上涨**
   命中率 = 52.7%（共 983 次反向信号）
   解释：当大盘今天大跌 >2% 时，科技股明天上涨的概率是 53%——大跌后反弹的概率略大于继续跌。

注意：这只是用 Profund 互为特征的演示。有了真正的 ETF 数据后（SPY、QQQ、TLT、UUP），特征更多、命中率会显著提升。

## 七、什么是 0.2% 的阈值？它在格式里的位置

公司标准化格式的第 5 行是 Average（平均值）。

假设我们预测 UltraBull 明天会涨，收集所有预测正确的日回报率，算出一个平均值。

**0.2% 的意思就是：这个预测的平均日回报率 >= +0.2% 或 <= -0.2%，才算有效。**

为什么选 0.2%？
- 一年大约 250 个交易日
- 0.2% x 250 = 50% 的年化回报率（这是非常强的信号）
- 大多数基金的历史平均日回报率在 0.03% 左右

| 统计项 | 数值 |
|--------|------|
| 全部 129 支基金全局平均 | 约 0.03% |
| ULPIX（UltraBull）历史平均 | 0.1613% |
| 合格基金（如 UOPIX）| 0.20% |
| 超强基金（如 INPIX 互联网）| 0.25% |

所以 0.2% 是一个很高的门槛——方向判断准确 + 涨幅可观时，才能达到。

## 八、完整的分析流水线（从数据到决策）

第1步：拿到 ETF 价格数据 -> SPY/QQQ/IWM 等历史收盘价
第2步：日期对齐 -> 所有 ETF 和 Profund 的数据按同一日期合并
第3步：建立预测模型 -> 对每支 Profund 基金找出最有预测力的 ETF 组合
第4步：输出预测 -> 每支基金未来 1-2 天的预测回报率
第5步：标准化格式 -> 按照公司格式（13行头部 + 降序数据）输出
第6步：投资决策 -> 基于有效信号给出调仓建议

## 九、注意事项

**误区 1：相关性不等于因果**
TLT 跌了之后股市涨，不一定是 TLT 跌导致的。但这不影响预测——我们只需要统计关系，不需要知道因果关系。

**误区 2：越近的历史越重要**
2008 年时的市场行为，和 2026 年的可能完全不同。建模时应给近期的数据更高权重。

**误区 3：杠杆基金不适合长期持有**
2x 和 -2x 基金由于波动损耗，长期持有往往会与 2 倍指数的表现有偏差。所以我们只做短期预测（1-2 天）。

**误区 4：不是每一天都适合做预测**
当信号不强时（比如 ETF 波动很小），模型应该给出无信号的结论，不做预测也是一种预测。
